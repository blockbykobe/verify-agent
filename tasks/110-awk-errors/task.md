Проанализируйте /var/log/nginx/custom_access.log и сформируйте отчёт в /tmp/error_report.txt. В отчёт должны попасть только запросы, завершившиеся ошибкой клиента или сервера (HTTP-статусы 4xx и 5xx), за исключением кода 404. Для каждого уникального IP-адреса, совершившего такие запросы, выведите количество ошибочных запросов и сам IP через пробел (формат: <количество> <IP>), отсортировав список по убыванию количества ошибок.
