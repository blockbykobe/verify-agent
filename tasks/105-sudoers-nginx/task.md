Разрешите пользователю deploy запускать через sudo без ввода пароля исключительно две команды: /usr/sbin/nginx -t и /usr/sbin/nginx -s reload. Конфигурацию разместите в /etc/sudoers.d/deploy-nginx. Убедитесь, что deploy не может запустить nginx с другими флагами (например, -c или -V) и конфигурация sudoers не содержит синтаксических ошибок.
