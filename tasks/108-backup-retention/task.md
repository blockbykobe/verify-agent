Напишите и выполните скрипт /usr/local/bin/backup-site.sh, который создаёт сжатый tar.gz архив директории /var/www/site в папке /var/backups/site/ с именем site_YYYY-MM-DD_HH-MM-SS.tar.gz. В архив не должны попасть директории cache, tmp и .git, но скрытый файл .env в корне сайта должен попасть в архив. После создания нового архива скрипт должен удалить старые архивы в /var/backups/site/, оставив только 3 самых свежих по времени модификации файла (mtime).
