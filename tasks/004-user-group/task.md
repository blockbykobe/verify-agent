Создай системную группу deploy и пользователя deploy (основная группа deploy, оболочка /usr/sbin/nologin, без домашнего каталога). Создай каталог /srv/app и сделай его владельцем deploy:deploy с правами 2775 (setgid), чтобы новые файлы в нём наследовали группу. Существующий файл /srv/app/config.ini тоже должен принадлежать deploy:deploy.
